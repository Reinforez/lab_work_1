Лабораторная работа номер 1. Скрипт собирающий параметры ОС.
1. Цель работы
   - изучить встроенные библиотеки Python для взаимодействия с операционной системой,
   - освоить работу с форматом данных JSON
2. Теоретический обзор
platform - встроенный модуль для получения информации об операционной системе, архитектуре процессора и версии Python.
os - встроенная библиотека для взаимодействия с операционной системой. входят функции не зависящие от используемой ОС.
sys - встроенный модуль, обеспечивает доступ к некоторым переменным и функция, взаимодействующим с интерпретатором Python.
json - позволяет кодировать и декодировать данные в удобном формате.
3. Структура кода
первым делом импортируем библиотеки и задаём словарь в котором будем хранить данные.
узнаём тип операционной системы и исходя из того, какая используется ОС осуществляется конкретные действия. (Windows,Darwin,Linux,Unknown)
для Windows используются атрибуты: platform.win32_ver (основная версия релиза, точный номер сборки, уровень установленного пакета обновлений, тип архитектуры ОС), hasattr (проверяет наличие определённого атрибута в библиотеке, в данном случае он нужен, чтобы узнать доступен ли атрибут на данной версии Pyhton, потому что platform.win32_edition был добавлен после версии 3.8), platform.win32_edition (возвращает редакцию текущей ОС), os.environ.get (возвращает значение переменной окружения в виде строки, если же найти не получилось, через запятую можно указать дефолтное значение), platform.machine (возвращает строковое значение архитектуры процессора)
для Darwin (MaxOS) используются атрибуты: platform.mac_ver (возвращает информацию о версии ОС MaxOS в виде кортежа: номер основного выпуска; кортеж, содержащий подробную информацию о сборке; строку с архитектурой процессора), os.path.expanduser (возвращает домашний каталог ткущего пользователя)
для Linus используются атрибуты: platform.freedesktop_os_release (возвращает словарь с данными об операционной системе: NAME, ID, VERSION_ID, VERSION, VERSION_CODENAME) для этого атрибута нужна проверка на возможные ошибки OSError если файл не найден в системе или у процессора нет прав доступа на его чтение, и AttributeError если версия Python ниже 3.10, так как до неё этого атрибута не существовало
для Unknown ОС использованы не многие библиотеки, работающие почти в каждой ОС: platform.node (возвращает строку, содержащую сетевое имя компьютера), sys.version (возвращает строку с подробной информацией о сборке Python) но для читаемости выводим только саму версию.
Сохранение в .json: чтобы не писать отдельно закрытие файла, записано в виде with open(..) as f. открываем нужный файл в режиме записи с кодировкой utf-8, что позволяет корректно сохранять кириллицу. json.dump присваиваем indent значение 4, что добавит 4 пробела, чтобы улучшить читаемость json файла. ensure_ascii=False заставляет записывать русские буквы как есть.
выводим на экран надпись с названием файла, где сохранена информация.
